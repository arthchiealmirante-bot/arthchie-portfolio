# Arthchie D. Almirante — Portfolio

A static, Netlify-ready portfolio site built with plain HTML, CSS, and JavaScript. No build step and no external runtime dependencies.

## Preview locally
Open `index.html` directly, or use VS Code Live Server.

## Deploy to Netlify
1. Zip or drag the whole folder into Netlify Drop, or connect a Git repository.
2. No build command is required.
3. Publish directory: `.`

## Before public launch
- Add your preferred public email / GitHub / LinkedIn links in the Contact section.
- Add a downloadable CV only if you want it publicly accessible.
- Keep operational screenshots sanitized. The bundled FIS preview is already redacted for public display.

## Structure
- `index.html` — page content
- `styles.css` — responsive layout and visual system
- `script.js` — interactions, project modal, animation, theme toggle
- `assets/` — optimized portfolio images
